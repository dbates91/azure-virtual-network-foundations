# Contributing to the AD Help Desk Lab

This is a public educational repository. Contributions must never contain actual user credentials, employee data, Azure subscription/tenant details, private keys or unsanitized screenshots. Use synthetic accounts only.

Submit changes through small pull requests that describe lab scope, approvals, threat/cost assessment, offline checks executed, test evidence and rollback. Do not claim actual AD execution if the change is documentation only. No GitHub Actions workflow may provision Azure or make unattended changes to AD.
