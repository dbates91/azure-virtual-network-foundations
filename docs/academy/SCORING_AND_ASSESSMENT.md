# Performance Scoring, Difficulty and Final Assessment

All scores must be based on observed learner work, not guessed resolutions or a calendar schedule.

| Skill area | Points |
| --- | ---: |
| Diagnosis and root cause reasoning | 30 |
| Verify → Scope → Inspect → Isolate → Resolve → Validate → Document → Prevent workflow | 20 |
| Correct, secure technical resolution | 20 |
| Verification and prevention | 15 |
| ITSM documentation and user communication | 15 |
| **Total** | **100** |

## Score interpretation

- **90–100:** Strong independent performance.
- **80–89:** Competent with minor weaknesses.
- **70–79:** Targeted remediation needed.
- **Below 70:** Repeat practice with different symptoms/root causes.

**Not scored:** Ticket not attempted, environment not accessible, purely simulated diagnostic evidence not investigated, or an unverified claim. Don't record "passed" based on copying previous solutions.

## Difficulty levels

1. **Guided:** explanation, commands and demonstration with a real or accurately simulated ticket.
2. **Assisted break/fix:** candidate investigates; hints used only when requested or assumptions are unsound.
3. **Independent:** no root cause or diagnostic path disclosed; candidate requests evidence, troubleshoots and closes the ticket.

Progress based on 80+ with correct validation/security, across multiple ticket categories, not speed alone. Track all support tickets by their `INC-###` IDs and evidence links.

## Final skills assessment — Days 28–30

Give unfamiliar incidents across the seven categories; include multi-ticket prioritization, customer questioning, identity verification, remote support, security escalation, root-cause analysis, recovery, and professional documentation. Measure:

- Number of independently resolved tickets vs attempted, with **actual validation**.
- Root cause accuracy, safety, average working time only if truly tracked.
- Communication/escalation quality.
- Strength/weakness by category and progression from guided to independent.

**Important:** Thirty elapsed days do not automatically establish job readiness; assess proven troubleshooting skill.
