# Help Desk Incident Ticket Template

**Ticket ID:** HD-___  
**Date:** —  
**Mode:** Planned / Guided lab / Blind lab / Verified lab  
**Reporter:** Fictional lab identity only  
**Priority:** Assessment required (impact × urgency)  
**Service / asset:** —

## User request and identity-verification record

Capture requester authorization and **the method of identity verification without storing security answers or secrets**. If identity cannot be verified, do not reset/unlock or disclose account details; escalate.

## Symptoms and scope

What was actually observed? Host/OU/group, affected users, timeline, impact, and recent changes. Distinguish facts from assumptions.

## Diagnostic reasoning and actions

List commands/GUI paths, timestamped sanitized outputs, competing hypotheses and their results. Explain why the chosen test matters.

## Resolution and security review

Document approval, least-privilege changes, rollback and any escalation. Do not put a password in a ticket or screenshot.

## Verification and communication

Confirm with a test account/client and the requester; record actual outcomes. Explain the resolution in plain language.

## Closure summary (interview format)

**Symptom → Evidence → Root cause → Corrective action → Validation → Prevention.**

**Status:** Not Started until performed.
