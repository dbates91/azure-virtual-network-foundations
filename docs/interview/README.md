# Help Desk Interview Practice

For each completed ticket, prepare a 60–90 second answer: **context → user/business impact → identity verification → troubleshooting hypothesis → evidence → least-privilege resolution → validation → ticket closure**.

Prompts:

- A domain user is locked out. What do you verify before unlocking, and how do you find the source of repeated attempts?
- What does DNS have to do with joining a workstation to Active Directory?
- What is the difference between a security group, an Organizational Unit and a Group Policy Object?
- How do you diagnose Access Denied when someone belongs to the correct group?
- What do you do if a user requests a password reset but cannot pass identity verification?
- What would you escalate, and what information belongs in a Jira ticket?

No answers should pretend that planned lab tasks were completed. Use observed screenshots and ticket notes as material becomes available.
