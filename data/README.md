# Synthetic Lab Identities

`lab-users.csv` contains **25 entirely fictional example employees**. These are not production accounts and are **not** credentials. Passwords are not included.

CSV fields: `FirstName`, `LastName`, `SamAccountName`, `Department`, `Title`, `Group`.

This data is intended for a closed lab. Review OU/group design before running scripts and **never import real employee exports into this public repository**. The provisioning script previews changes by default and requires explicit execution authorization.
